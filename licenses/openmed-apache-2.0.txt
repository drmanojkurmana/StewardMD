OpenMed - attribution notice

phi-india.js adapts the identifier coverage of OpenMed's `india_health_id`
de-identification policy (ABHA Address, UPI ID, masked Aadhaar, Indic-script
digits, Indian identifier labels). The StewardMD code is an independent ES5
implementation; no OpenMed source file or model weight is included.

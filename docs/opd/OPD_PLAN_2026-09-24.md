       same commit as the patient (duplicates impossible across devices and clinics). Format

       Client stops minting; it shows what the server returns.
- [x] 2. Server resolve (`GET /identity/resolve`) and revocation (`POST /identity/revoke`) so a lost
       Ni-Key card stops working on every device, not one.

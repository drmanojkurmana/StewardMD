## 1. Goal

Connect Hospital (Connect Agent) must let a doctor connect an unfamiliar hospital EMR from a phone:
doctor signs in themselves → agent explores in the SAME authenticated browser session → discovers the
EMR's data endpoints → maps to StewardMD → human approves → the hospital appears in Ward Sync and any
authorised doctor reads real data through the approved adapter.

**Gold standard:** the owner's hand-built GHIS integration (`functions/api/ghis/[[path]].js`). The agent
must rediscover the same endpoints **without being given them**.

**Owner's core rule (2026-09-13):** *"Do not save an endpoint as discovered until the system has proven
what that endpoint does."* Loop: `EXPLORE → OBSERVE → GEMINI → EXECUTE → VERIFY → LEARN`.
Spec: `docs/connect/agent-modes-plan.md` § "Proven endpoints".

**Security (non-negotiable):** no cookies/passwords to Cloudflare; no server-side EMR cookie jar; PHI-free
structure only to the model (paths, key names, column labels, counts); read-only (never order, prescribe,
print, sign, submit, delete).

### Architecture now in place

**Proof loop** (`connect-agent/phone/prove.mjs`) — per captured screen:
1. **OBSERVE** — the page observer (`connect-agent/discovery.mjs`) keeps a page-realm-only replay buffer
   `window.__SMD_REPLAY__` (exact url, body, response *structure*). Never drained to the server. Sign-in
   bodies skipped. Same-origin only; repeated polls collapse to one entry.
2. **GEMINI** — brain op `pick-endpoint` ranks candidates from structure only
   (`data | prerequisite | lookup | ping | shell`).
3. **EXECUTE** — each candidate is re-issued *from inside the hospital page* in that order.
4. **VERIFY** — reply must carry ≥50% (and ≥3) of the on-screen cell values, **and** Gemini (`verify` op)
   must agree the reply's columns are that resource. Otherwise → next candidate.
5. **LEARN** — every field traced to a source: `{from:'worklist', field:'Patient ID'}`,
   `{from, fields:[a,b], join:'-'}`, `{constant}`, `{token}`, `{today:'DD-Mon-YYYY'}`, `{page}`, `{empty}`.
6. Unproven view ⇒ **no endpoints saved** (`view.proof.status`), falls back to page reading.

**Runtime** (`adapter-runtime.mjs` `executeProven`) sends exactly the proven calls; patients carry their
list row as non-enumerable `_row`; `readPatientDetails` follows `labs → labs-detail` chains via `_of`.

**Brain** (`functions/_connect/agent/brain.js`), 6 ops: `classify`, `map-columns`, `next`, `verify`,
`pick-endpoint`, `plan-controls`. PHI gate refuses any string with 3+ consecutive digits or `@`.

  ADC token from the metadata server, calls `locations/global` `gemini-3.8-flash`.
  URL: `https://connect-agent-brain-911280405587.asia-south1.run.app`

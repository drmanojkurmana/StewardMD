## A. On your phone now (test directly in the app)

### 1. One-tap prescription → WhatsApp / print
Open a patient → **Assessment** → fill Dx + add meds/plan → Save → in the post-save panel tap **"Share prescription (WhatsApp / print)"**. The OS share sheet opens → pick WhatsApp (or Print / Save-PDF). Works offline; nothing logged server-side.

### 2. Refer patient + Visit summary (medico-legal)
Same post-save panel: **"Refer patient"** (asks who + why → shareable referral letter) and **"Visit summary"** (full, timestamped, "electronically generated by Dr X" record → share/print).

### 3. Smart Rx pad (safety) — *open the Rx pad (needs a verified doctor login)*
Add two interacting drugs → a **Safety checks** panel appears under the list (critical/major/moderate + duplicates). Type an allergy in the new **allergies** field that matches a drug → a red allergy warning shows. Rechecks live as you add/remove drugs.

### 4. Rx templates / favourites
In the Rx pad, add your usual drugs → **"Save set"** → name it (e.g. "URI"). Next time, pick it from **"Apply a saved Rx set…"** → all the lines drop in. (Saved on the device.)

### 5. Drug price + generic substitute
In the Rx pad, pick a drug → a green line shows **"₹ lowest brand: X ₹NN (vs ₹YY same molecule)"**. Tap the brand field to switch to the cheaper brand. (Needs network; hides silently if unavailable.)

### 6. Voice-to-Rx
In the Rx pad tap **"Dictate"** and say e.g. *"amox 500 TDS 5 days"* → it adds a parsed drug line (drug→generic, dose, frequency, duration). Edit after. (Needs the on-device voice engine.)

### 7. Explainable MaiK + never-guess (in the consult)
Assessment → **Ask MaiK** → treatment suggestions now show a **source line** (guideline/textbook) under each. When the top diagnoses are genuinely close, a yellow **"MaiK is not confident — treat as a checklist, add findings"** banner appears instead of a confident answer.

### 8. Every patient has an Assessment button
Any patient row (and the in-consult card) shows **Assessment**; tapping **Start/Play** opens it directly.

### 9. ICU / Ward patient search
Open ICU → **Saved patients** → with >4 patients a **search box** appears: type a name, diagnosis, bed, or StewardMD ID to filter instantly.

### 10. Doctor analytics
Queue → **Analytics** now shows **No-show rate, Completion rate, Patients today** (plus Avg wait/consult, ETA accuracy, peak hours). Revenue + follow-up-compliance tiles appear once those are enabled server-side (see B).

### 11. Set follow-up (growth loop)
Post-save panel → **"Set follow-up"** (shown when FollowCare is on) → opens the FollowCare enrolment prefilled with the patient → schedules automatic check-ins that pull them back to you.

### 12. Referrals inbox (flag OFF — see C to turn on)
Built and shipped but **off by default** (zero risk). Turn-on steps in section C.

## D. Deliberately deferred (and why — I didn't want to ship anything broken)

- **Lab-trend sparklines:** the consult's lab data is a list of lab *orders*, not per-analyte numeric values over time. A real trend needs a GHIS results-fetch + analyte-parse pipeline. Building it against absent data would've shipped an empty chart — deferred until that pipeline exists.
- **Dedicated recall / tokenized patient live-link:** substantially covered already — "Set follow-up" (#11) schedules automatic review nudges, and the patient gets their Rx/summary via the share features. A dedicated review-appointment pathway + a live patient web page are a clean next step.

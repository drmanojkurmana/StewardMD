# ICD Search — data provenance (2026-09-04)

Loaded once, directly into the remote D1 (`stewardmd-icd`) via `wrangler d1 execute --remote`.
No ingestion script is checked in (the parse was a one-off ~80-line Python script run against two
downloaded public files) — this note exists so a future reload/refresh knows exactly where the
data came from and how it was shaped.

## ICD-10 — 71,704 codes

Source: [`k4m1113/ICD-10-CSV`](https://github.com/k4m1113/ICD-10-CSV) (`codes.csv`), a public,
freely-redistributed CSV of ICD-10-CM (the US clinical-modification release, the most complete and
most readily available machine-readable ICD-10 edition — used here as the ICD-10 code set since
it's a superset of the WHO 4-character ICD-10 categories most Indian schemes/hospitals cite).

CSV columns: `category(3-char), order, code(no dot), short_description, long_description, ...`.
Parse: dotted code = first 3 chars + `.` + remainder (`A000` → `A00.0`); `title` = long
description; `chapter` = the 3-char category.

## ICD-11 — 34,663 codes

Source: WHO's own public "Simple Tabulation" export for the ICD-11 MMS (Mortality and Morbidity
Statistics) linearization — no API registration required, direct download:
`https://icdcdn.who.int/static/releasefiles/2024-01/SimpleTabulation-ICD-11-MMS-en.zip`
(also reachable via the picker at `https://icd.who.int/dev11/downloads`). WHO release dated
2024-01-21.

Tab-separated file, one row per entity in the classification tree (chapters, blocks, categories).
Only rows with a non-empty `Code` column were loaded (chapters/blocks have no code and were
skipped — they're a browse aid StewardMD doesn't currently use). `title` had its leading
`- - -`-style depth-indent dashes stripped; `chapter` = the `ChapterNo` column; `is_leaf` = the
`isLeaf` column.

## Load

```
wrangler d1 execute stewardmd-icd --remote --file=functions/db/icd_schema.sql
# then N batched multi-row INSERT files, ~4000 rows each, generated by the one-off parser
```

## License / use

Both are public government/international-body reference releases (WHO ICD-11; CMS-published
ICD-10-CM code lists are US public domain / freely redistributable — the GitHub source repo itself
redistributes them under no additional restriction). This is non-PHI classification reference
data — code + title only, no patient data touches this table.

## Refreshing

WHO publishes a new ICD-11 MMS release periodically (the loaded release is 2024-01). To refresh:
download the current `SimpleTabulation-ICD-11-MMS-en.zip` from the downloads page above, re-run
the same parse shape (tab-separated, `Code`/`Title`/`ChapterNo`/`isLeaf` columns), and either
`DELETE FROM icd_codes WHERE system='ICD-11'` before reloading, or upsert by `id` (`"icd11:" + code`
is stable across releases for an unchanged code).

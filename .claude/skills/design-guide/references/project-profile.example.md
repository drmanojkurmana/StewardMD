# Project Profile Example

Copy this to `.design-guide/profile.md` inside a project when the project needs stable frontend direction.

```text
Product type:
Audience:
Primary workflows:
Use frequency:
Reference products:
Brand constraints:
Preferred density:
Preferred motion:
Preferred review artifacts:
Artifact presentation:
Approval policy:
Required breakpoints:
Existing design system:
Existing icon family:
Avoid:
Required checks:
```

Example:

```text
Product type: creator dashboard
Audience: non-technical content operators
Primary workflows: upload media, review generated output, publish
Use frequency: daily
Reference products: Canva editor, YouTube Studio
Preferred density: medium
Preferred motion: restrained
Preferred review artifacts: responsive HTML for major new screens
Artifact presentation: open HTML on a shared desktop; attach screenshots when remote
Approval policy: confirm exploratory directions before full implementation
Required breakpoints: 1440, 1024, 390
Avoid: marketing hero, nested cards, AI-purple gradients
Required checks: typecheck, desktop screenshot, mobile screenshot
```

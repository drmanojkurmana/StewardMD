# 更新日志

这里记录 `design-guide` 的重要变更，版本号遵循语义化版本规范。

## [Unreleased]

### 新增

- 支持 `en` 和 `zh-CN` 的语言契约与消息资源。
- CLI 帮助、人类可读状态和错误输出支持本地化，并在缺失时回退英文。
- 增加双语维护/发布文档和翻译资源一致性测试。

## [0.1.1] - 2026-08-07

### 修复

- Gitee 标签同步不再强制更新镜像的 `main` 分支。
- 密钥扫描覆盖 README、工作流和测试文件，并支持从非 Git 源目录运行。
- `design-guide-doctor.py` 会拒绝 `VERSION` 与 `design-guide.json` 不一致的情况。
- 提供方冒烟测试会在发布版本源不一致时拒绝执行。

## [0.1.0] - 2026-08-07

### 新增

- Level 0/1/2 设计深度路由和探索式工作的用户确认门。
- 独立 HTML 自动呈现、受管理评审服务和机器校验的实现契约。
- 项目情报、预览、截图、视觉差异和严格浏览器 QA 工具。
- 已有产品/页面设计评估、Scope Gate、行为回归样例和专项评审模板。
- Codex、Claude Code、Cursor、Qwen Code 的跨 AIDE 同步与诊断。

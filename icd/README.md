`window.SMD_ICD.localSearch()`, which `maik-engine.js` `icdCandidates()` falls back to when
offline. Shipped into the native bundle by `scripts/build-www.sh`.

Refresh: re-run the build script; it always downloads fresh, never fabricates rows, and fails
loudly if the source is unreachable.

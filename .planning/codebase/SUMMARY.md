# Codebase Map Summary

**Analysis Date:** 2026-09-11

StewardMD is an offline-first clinical decision support, surgical intelligence, and hospital rounding platform. It is designed as a buildless vanilla JavaScript PWA wrapped inside Capacitor 8 for native iOS and Android deployment.

## Key Findings

- **Architecture:** Buildless pure vanilla ES JavaScript client, packaged via `scripts/build-www.sh` into `www/` and compiled with Capacitor 8 into native iOS and Android binaries.
- **On-Device AI Capabilities:** Embedded native Capacitor plugins for local on-device LLaMA clinical inference, Whisper ambient voice scribing, and dermatology vision classification.
- **Clinical Domains:**
  - `SURGX`: Surgical operative notes, procedure step packs, and zero-knowledge encrypted backups.
  - `SKNX`: Dermatology lesion analysis, image comparison, and evidence-grounded reports.
  - `THOREX`: Chest X-ray analysis powered by ONNX Runtime Web and multi-modal correlation.
  - `WARDSYNQ`: Inpatient ward rounding, bed management, and live GHIS hospital system sync.
  - `VOICE`: Ambient doctor-patient consultation transcription and automatic EMR/FHIR field mapping.
- **Testing:** Comprehensive test suite in `test/*.test.mjs` executed using Node.js's native test runner (`node:test`) with experimental SQLite and mocking support.
- **Current Quality State:** The test suite passes extensively across security and clinical protocol boundaries, with one identified minor cache-tag test failure in `test/surgx-content.test.mjs`.

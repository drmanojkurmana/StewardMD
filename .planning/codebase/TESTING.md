# Testing Strategy & Patterns

**Analysis Date:** 2026-09-11

## Test Architecture

**Runner:**
- Native Node.js test runner (`node:test`, `node:assert/strict`)
- Flags: `--experimental-test-module-mocks --experimental-sqlite`
- Invocation: `npm test` runs all `test/*.test.mjs`, `test/connect/*.test.mjs`, and `rx-build.test.mjs`.

## Test Structure & Categories

1. **Clinical Invariant & Protocol Verification:**
   - Validates that calculators, syndrome trees, drug formulations, and surgical step packs parse correctly and link to valid targets (`test/surgx-calc-links.test.mjs`, `test/surgx-content.test.mjs`).
   - Asserts that drug dosages and emergency flags reproduce authoritative guidelines without deviation.

2. **Security & Cryptography Tests:**
   - Validates zero-knowledge backups, ciphertext integrity, password authentication, and salt freshness (`test/surgx-backup.test.mjs`).
   - Ensures that backups contain no raw patient identifiers in filenames, metadata, or unencrypted headers.

3. **Domain Integration & Mocking:**
   - Tests SQLite schema creation and queries using `--experimental-sqlite`.
   - Mocks Capacitor native plugin interfaces to test business logic in Node without requiring iOS Simulator or Android Emulator.

4. **Clinical Decision Evaluation:**
   - `npm run eval:maik` and `npm run eval:maik:answers` run clinical accuracy benchmarks against reference medical questions and diagnostic datasets.

## Running Tests

```bash
# Run all unit and integration tests:
npm test

# Run a single focused test file:
node --experimental-test-module-mocks --experimental-sqlite test/surgx-backup.test.mjs

# Run clinical reasoning evaluations:
npm run eval:maik
```

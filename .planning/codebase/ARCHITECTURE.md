# Architecture Overview

**Analysis Date:** 2026-09-11

## Architecture Pattern

StewardMD follows an **Offline-First, Buildless PWA + Native Bridge** architecture:
1. **Core Client**: Modern vanilla ES JavaScript and modular CSS at the repository root. It requires no bundler (no Webpack, Vite, or Rollup), ensuring instant hot-reloading, zero build churn, and clean auditability.
2. **Native Runtime Wrapper**: Capacitor 8 bridges the web application to iOS and Android, injecting custom native plugins for high-performance ML models (LLaMA, Whisper, Vision ONNX) and hardware access (Biometrics, Camera, Bluetooth, SQLite).
3. **Distribution Assembly**: `scripts/build-www.sh` synchronizes root assets, dependencies, and manifest files into `www/`, which is then embedded into the Xcode (`ios/`) and Android Studio (`android/`) projects.

1. **SURGX (Surgical Intelligence)**:
   - Structured operatory note generation, standardized surgical step packs, checklist verification.
   - Client-side AES-GCM encrypted backup directly to surgeon's Google Drive.
2. **SKNX (Dermatology & Skin Vision)**:
   - On-device vision model and cloud vision fallback (`sknx-vision.js`, `sknx-cloudvision.js`).
   - Lesion comparison tracking over time (`sknx-compare.js`).
3. **THOREX (Pulmonology & Thorax Intelligence)**:
   - OnnxRuntime Web (`thorex-ort.js`) and native acceleration for chest radiograph analysis.
   - Multi-modal clinical report synthesis (`thorex-report.js`).
4. **WARDSYNQ (Inpatient Ward Rounds & GHIS)**:
   - Hospital ward rounding workflow, bed tracker, clinical alert engine.
   - Shadow-boot and live sync with Government Hospital Information Systems (`wardsynq-ghis-live-boot.js`).
5. **VOICE SCRIBE (Ambient Clinical Scribe)**:
   - Ambient voice consultation recording, speaker diarization (`voice-diarize.js`), vitals extraction (`voice-vitals.js`), EMR auto-mapping (`voice-emr-map.js`).
6. **Clinical Calculators & Specialty Engines**:
   - Evidence-based calculators (`calculators.js`), specialty guidance (`ws-surgery.js`, `ws-paediatrics.js`, `ws-obstetrics_gynaecology.js`, etc.).

## Data Flow & Security Model

- **Zero-Knowledge Patient Identity**: Clinical notes, photos, and backups strip all direct identifiers prior to any sync.
- **Client-Side Encryption**: Backups stored in external clouds are encrypted using PBKDF2 key-stretching and AES-GCM before transport.
- **Offline First**: All clinical workflows remain fully operational without internet connectivity, storing state locally in SQLite and encrypted preferences.

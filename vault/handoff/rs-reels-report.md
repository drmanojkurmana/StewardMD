## What was built

- Phase 0: [PrepReels architecture note](/Volumes/WD BLACK SN7100 1TB Media/wt-prep-reels-sound/vault/plans/PrepReels-architecture-note.md) — audit of prep-loader, PREP._host, FSRS store, bank cache, CSP, test and build conventions; chosen files; YouTube policy checklist; synthetic fixtures list. `graphify-out/graph.json` does not exist in this worktree, so no graph query was possible.
- Phase 1: Study Feed (default mode) in [prep-medigram.js](/Volumes/WD BLACK SN7100 1TB Media/wt-prep-reels-sound/prep-medigram.js) + [prep-medigram.css](/Volumes/WD BLACK SN7100 1TB Media/wt-prep-reels-sound/prep-medigram.css) (`.pn-mg-*`) + pure logic in [prep-medigram-data.js](/Volumes/WD BLACK SN7100 1TB Media/wt-prep-reels-sound/prep-medigram-data.js): candidate contract validation at build and serving boundary, hard eligibility (exam, disputed/hidden, rights, expiry, clinical review), deterministic ranking from due reviews, mistakes, exam and timetable, 3:1 cadence, finite missions, Finish session, save/skip/"I don't understand"/report, offline-safe fixtures. Loaded lazily via prep-loader only when `smd_prep_medigram` is on.
- Phase 2: Clinical Discovery and Smart Break modes, each behind its own sub-flag and off by default; first-party micro-lesson cards from lesson-style assets; English/Hindi/Telugu language field with captions plus `clinicalReview` gate (item hidden unless reviewed for that language); official YouTube nocookie embed adapter in [prep-medigram-media.js](/Volumes/WD BLACK SN7100 1TB Media/wt-prep-reels-sound/prep-medigram-media.js) behind `smd_prep_medigram_youtube` (off), graceful when disabled, offline or malformed, with pause and release on navigation and background; source labels and report action on every item.
- Phase 3: post-video retrieval checks (the question after a lesson is marked as its retrieval check) and delayed recall through the existing FSRS-6 in specialty-core, only on a valid answer or grade; mistake-tag personalisation in ranking; cadence A/B config 2:1, 3:1, 5:1 with pre-registered, consent-aware, local learning-outcome events only; MaiK concept-explain hook as a stub that calls the existing `PREP_ASK.open` path when it exists and otherwise shows the stored explanation.
- Pilot kit: [PrepReels pilot protocol](/Volumes/WD BLACK SN7100 1TB Media/wt-prep-reels-sound/vault/plans/PrepReels-pilot-protocol.md) — 30 learners, 4 weeks, matched topics, primary outcome 7-day delayed recall, pre-registered analysis. Protocol only; no results claimed.

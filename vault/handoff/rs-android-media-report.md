Branch `prep-reels-sound-2`, worktree `wt-prep-reels-sound`. Android only. **Native changes need a store build to reach phones.** No Spotify approval request sent or drafted. No paid calls; no network in tests. Nothing about what is playing goes to analytics, the AI Tutor, or storage.

## What was built

- **[PrepMediaListenerService.java](../../local-plugins/capacitor-prep-sound/android/src/main/java/in/stewardmd/prepsound/PrepMediaListenerService.java)** (new): a `NotificationListenerService` that reads **NO notification content** — both callbacks ignore their `StatusBarNotification` entirely. It exists only so `MediaSessionManager.getActiveSessions(componentName)` is allowed after the user enables PrepNucleus in Settings > Notification access. Declared in the plugin [AndroidManifest.xml](../../local-plugins/capacitor-prep-sound/android/src/main/AndroidManifest.xml) with `android:permission="android.permission.BIND_NOTIFICATION_LISTENER_SERVICE"` and the `NotificationListenerService` intent-filter; the no-content rule is stated in the class comment, the manifest comment, and the JS permission copy.
- **[PrepSoundPlugin.java](../../local-plugins/capacitor-prep-sound/android/src/main/java/in/stewardmd/prepsound/PrepSoundPlugin.java)** (extended, same `:stewardmd-capacitor-prep-sound` module): `mediaAccessStatus() -> {granted}` (Settings `enabled_notification_listeners` check with a `getActiveSessions` fallback, so revocation reads as `granted:false`), `openMediaAccessSettings()` (`Settings.ACTION_NOTIFICATION_LISTENER_SETTINGS`), `nowPlaying()` -> `{ granted, hasSession, app (label), package, title, artist, album, artwork, durationMs, positionMs, isPlaying, actions {play,pause,next,previous,seek} }` from `MediaMetadata`/`PlaybackState` (artwork = JPEG base64 data URL scaled to max 256px; position advanced by elapsed time while playing; denied/no-session resolve the same shape with `hasSession:false` instead of rejecting), `control({action, value?})` for `play|pause|next|previous|seek(ms)` via `MediaController.TransportControls` (rejects `media-access-denied` / `no-session` / `unsupported-action` / `seek-value-required`), and the `nowPlayingChanged` event from a `MediaController.Callback` (+ `OnActiveSessionsChangedListener` rebind when the top app changes). PrepNucleus's **own ambience session is always skipped** (package match). The callback/sessions listener are registered only while JS has a `nowPlayingChanged` listener, unregistered when the last listener is removed (`addListener`/`removeListener`/`removeAllListeners` overrides) and when the app backgrounds (`handleOnPause`; `handleOnResume` re-registers if JS still listens). Track values are never logged. Existing playback/secure-storage methods are byte-identical in behaviour; `isAvailable()` only gained `systemMedia:true`.
- **[prep-sound-system.js](../../prep-sound-system.js)** (new): `window.PREP_SOUND_SYSTEM`, ES5, node-testable pure core. Produces **exactly** the player-UI contract — model `{ provider:"system", providerLabel:<app label>, title, artist, album, artworkUrl, durationMs, positionMs, isPlaying, shuffle:null, repeat:null, liked:null, volume:null }` (null when no session) and caps `{ play, pause, next, previous, seek, shuffle:false, repeat:false, like:false, volume:false, artwork }` mapped from PlaybackState actions (artwork true only when art exists). `status()` -> `unsupported | needs-access | no-session | ready` for the permission card, `requestAccess()` opens Notification access settings, `nowPlaying()/getNowPlaying()`, `control()` + `play/pause/next/previous/seek`, `subscribe()/onNowPlayingChanged()` returning an unsubscribe that removes only that Capacitor listener handle. Permission copy (exported as `PERMISSION_EXPLANATION`, asserted in tests): "Lets PrepNucleus show and control the song playing in your music app. PrepNucleus does not read your notifications." **Inert on web/iOS**: no plugin / non-Android / pre-media plugin build all report `supported:false` with typed `unsupported:system:*` results, never a fake success. No storage, fetch, analytics or history anywhere in the file (test-asserted).

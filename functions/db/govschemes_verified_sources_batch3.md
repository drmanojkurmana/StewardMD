## West Bengal (Swasthya Sathi)
Status: VERIFIED-TABLE

- Entry: https://swasthyasathi.gov.in home page, footer/quick link "Package Details" -> https://tms.swasthyasathi.gov.in/portal/SSPPackage.asp
- Search form (name `frm`), two selects: `cbo_pckg` (Grade) and `cbo_Procedure` (speciality). Button "Show Data" runs `selcmd()` which POSTs the form to `SSPPackage.asp?dw=<cbo_pckg>`. A plain GET with query params returns no data; it must be a POST.
- Grade select values: 2=Grade A, 3=Grade B, 4=Grade C, 7=Grade R, 1=Critical Illness Package, 5=Implants ORTHOPAEDICS, 6=Implants CARDIO, 11=Implants ONCOSURGERY, 8=Investigation Package - NABH, 9=Investigation Package - Non-NABH.
- Procedure select: 33 specialities (CARDIOLOGY, CHEMO DRUG, CHEMO THERAPY, CTVS, DENTAL, EAR, ENDOCRINOLOGY, ENDOSCOPIC PROCEDURES, ENT, GASTROENTEROLOGY, GENERAL PEDIATRICS, GENERAL SURGERY (=6), HAEMATOLOGY, HYSTEROSCOPIC, MEDICAL CONDITIONS, ..., UROLOGY /NEPHROLOGY). Leaving it blank returns the whole grade.
- Observed (POST cbo_pckg=2, cbo_Procedure blank): HTML table, columns `SrNo | Procedures | PackageId | PackageName | Amount`, 1921 data rows, single page, no pagination. Sample: `1 | GENERAL SURGERY | SS00600001 | INJURY OF SUPERFICIAL SOFT TISSUES - SECONDARY SUTURE OF WOUNDS | 1800`; last: `1921 | UROLOGY /NEPHROLOGY | SS01800131 | Haemo-dialysis per sitting (repeated use...) | 1200`.
- With cbo_Procedure=6 (GENERAL SURGERY) same columns, 321 rows.
- Code format `SS0NNNNNNN` (SS + 8 digits). Stratified by hospital grade (A/B/C/R) as reported; each grade is a separate POST.

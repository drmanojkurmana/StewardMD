# Diagnostic accuracy audit: Clinical Reasoning + Antibiotic Decision engine (2026-09-26)

Measurement only. No engine code changed. Everything below was run against the real app in
headless Chromium (`test/serve.mjs` + CDP), at `32f0f192`.

- `test/run-case-validation.mjs`: the existing gold-case replay (dx + StewardRAG treatment).
- `test/run-dx-audit.mjs` (new): the same gold cases three ways (curated keys, chart as text,
  complaint only), the antibiotic gate, the OPD re-ranker, and a held-out text set.
- `test/dx-heldout.json` (new): 40 fresh doctor-style vignettes never used to tune the engine.

## Headline

| Input path | n | Top-1 | Top-3 | Correct dx absent |
|---|---|---|---|---|
| Curated engine keys (gold cases) | 491 | **69%** | **92%** | 4 |
| Same cases, full chart as text | 491 | 22% | 41% | 64 |
| Same cases, presenting complaint only | 491 | 19% | 34% | 151 |
| Held-out doctor text (new) | 40 | 40% | 55% | 11 |

(9 of the 500 gold cases have no `acceptableIds` and are excluded; the existing runner counts them
and reports 354/500 = 71% top-1, 460/500 = 92% top-3.)

**The ranker is decent; the text front door is the bottleneck.** When a clinician taps the right
findings, the correct diagnosis is in the top 3 for 92% of cases. When the same case arrives as
text (OPD Ask MaiK, case notes, voice), extraction recovers only ~37% of the gold finding keys and
accuracy falls to 22 to 40% top-1.

## Antibiotic decision (the infection gate)

"Gate says antibiotics" = `very_likely` or `likely` (the wizard's red "Immediate antibiotics
required" / orange "Antibiotics recommended"). Truth = gold case lists at least one antibiotic.

| Input path | Abx indicated: gate says abx | Abx NOT indicated: gate says abx |
|---|---|---|
| Curated keys | 162/172 (94%) | 49/319 (15%) |
| Chart text | 115/172 (67%) | 81/319 (25%) |
| Held-out text | 9/23 (39%) | 3/17 (18%) |

Time-critical infections (meningitis, septic shock, sepsis, febrile neutropenia, necrotising
fasciitis, SBP, cholangitis, endocarditis, brain abscess; n=35): gate flags antibiotics in 33/35
with curated keys (both misses are SBP), 24/35 from chart text.

Antibiotic choice (StewardRAG treatment vs gold antibiotics, 175 scored): 139/175 (79%) overall;
115/137 (84%) when the top-1 dx is right, 24/38 when it is wrong.

## Findings, by severity

1. **Viral / self-limited infections trigger the antibiotic gate.** 14/14 gold viral or
   self-limited cases (dengue x3, chikungunya x2, URTI x2, viral hepatitis x3, viral meningitis,
   acute bronchitis x2, gastroenteritis) are gated `likely`/`very_likely`. Verified in the live
   workspace: a dengue case renders "Infection very likely. Infection leads the differential,
   empiric antimicrobial therapy is appropriate." `gate()` (`reasoning.js:975`) scores infection
   vs non-infection only; it never consults `SYNDROMES[id].antibioticRelevant`, which is already
   `false` for MALARIA, DENGUE, CHIKUNGUNYA, VIRAL_HEPATITIS, MIXED_MALARIA (and is set `true` for
   URTI, VIRAL_MENINGITIS, ACUTE_BRONCHITIS, GASTROENTERITIS in `kb/treatments/*.json`). The wizard maps the gate straight to
   severity (`abx-wizard.js:37`, `:772`, `:799`). For a stewardship engine this is the most
   important defect.
2. **Text extraction misses common bedside phrasing.** `DX.findingsFromText` returns nothing for
   "burning micturition, frequency, urgency, suprapubic pain", "red hot swollen first MTP joint",
   "periumbilical pain shifting to right iliac fossa, rebound tenderness", "new murmur, splinter
   haemorrhages, IV drug use"; only `fever` for "red hot swollen tender leg, spreading erythema",
   "fever 38.8, ANC 300, on chemotherapy" and "ascitic fluid PMN 450, cirrhosis"; `weight` (a false
   positive) for "hot swollen painful knee, unable to bear weight". "chills", "rigors" and numeric
   labs (lactate 4.2) are not extracted. Negation and vitals parsing work well.
3. **Sparse input has no base-rate prior.** `fever` alone ranks HLH first (30) with gate
   `noninfective`; fever + rigors ranks HLH above malaria. This is why "fever, ANC 300" (febrile
   neutropenia) and several held-out infections land on HLH / serotonin syndrome / thyroid storm
   with antibiotics withheld.
4. **Dangerous dx-to-drug misses** (curated keys, dx wrong so drugs wrong): SBP -> hepatic
   encephalopathy x3 (lactulose/rifaximin, no ceftriaxone); variceal bleed -> hepatic
   encephalopathy (no prophylactic ceftriaxone); scrub typhus -> typhoid (ceftriaxone, which does
   not cover Rickettsia); TB meningitis -> bacterial meningitis (no ATT); septic arthritis ->
   cellulitis; HAP -> CAP x2 (narrow regimen for hospital-acquired).
5. **Regimen does not follow host modifiers in the grounded plan.** ESBL pyelonephritis, MRSA
   cellulitis, Pseudomonas bronchiectasis, neutropenic erysipelas, DR-TB all resolve to the
   default first-line regimen in `StewardRAG.buildPackage`. The classic output in `app.js` does
   have `assessMDRRisk` / `getMDRBroadeningAdvice`, so check which surface the doctor sees before
   treating this as a bug.
6. **Confidence is not calibrated.** Curated keys: 51 of 208 cases scored 100 are wrong. From
   text: top-1 accuracy is 13 to 40% across every score band. The vault already says scores are
   ranking values, not probabilities; the UI still labels them confidence.
7. **Tooling.** `kb/validation/baseline.json` is stale: the runner reports 18 "regressions"
   (neuro/tox cases now losing to Carbamate, Alcohol withdrawal, Uraemic encephalopathy, PRES),
   but the same 354/500 reproduces at `31a64ece`, so none come from this week's commits. No CI
   workflow runs the case replay. `test/run-opd-dx-bench.mjs` Part A runs in a Node VM where the
   51 infectious syndromes do not load (CAP scores absent there, #1 in the browser), so its
   numbers are not valid. The OPD re-ranker is slightly worse than workspace ordering (324 vs 340
   top-1 on curated keys).

## Caveats on the gold set

- The 492 `gc_*` cases were AI-authored with engine keys already chosen, and some were used for
  recall fixes (`test/run-recall-infective.mjs`), so the 69%/92% is an optimistic, partly
  in-sample figure. The held-out 40 are small but independent.
- Some gold antibiotic labels are questionable (dengue expecting ceftazidime-avibactam /
  polymyxin, chikungunya and acute bronchitis expecting piperacillin-tazobactam). Several "misses"
  are equivalent regimens (aciclovir vs acyclovir, penicillin V vs amoxicillin, cefuroxime vs
  ceftriaxone+metronidazole). Adjusted antibiotic-choice accuracy is likely mid-80s.
- MaiK (Gemini tier) was not measured: no key in this environment.

## Suggested order of work (not done here)

1. Gate: return `possible`/`noninfective`-style "no antibiotics" when the leading infection is
   `antibioticRelevant === false`, and review the `true` on URTI, viral meningitis, acute
   bronchitis, uncomplicated gastroenteritis. Behind a flag, re-run both harnesses.
2. Extraction: add synonyms for the misses above and numeric lab thresholds (lactate, ANC,
   ascitic PMN, platelets). Gate on the held-out text score, not the curated one.
3. Base rates: a small prior (region/setting) so fever alone does not lead with HLH.
4. Rebaseline `baseline.json` after owner review, and wire the replay into CI.
